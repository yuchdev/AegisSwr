## 🛠️ 2. Step-by-Step Design Requirements

### Step 1: Core Orchestrator Design (ADR-001)

Direct `LeadArchitect` to design a state-graph router. The state machine must handle asynchronous agent turn-taking and implement a weighted consensus evaluation metric:

$$CS = \frac{\sum_{i=1}^{n} (W_i \cdot S_i)}{\sum_{i=1}^{n} W_i}$$

The architect must document the consensus threshold model inside `docs/adrs/ADR-001_CORE_ORCHESTRATION.md`.

### Step 2: Formulate the Unified Pluggable Interface Model (ADR-002)

Direct `BackendEngineer` to define five explicit plugin backend classes. The system must accommodate:

1. **AI API Backend:** Token streaming and foundation model communication interfaces.
2. **Debug Backend:** Abstractions for processing system binary dumps cross-platform.
3. **Storage Backend:** Multi-tier routing to Object Stores, Relational Data, and Vector databases.
4. **Log Backend:** Stream and batch connection adaptors for external observability products like **Fluentd, Fluent Bit, ELK (Elasticsearch/Logstash), Datadog, or Splunk**.
5. **Code Backend:** Deep local and remote repository connection managers with support for **Git and Mercurial**. Must expose tools to parse diff history, track commit lines, and identify system file regressions occurring right before an incident window.

The engineer must record this structural approach in `docs/adrs/ADR-002_PLUGGABLE_BACKENDS.md`.

### Step 3: Validation Sandbox Engineering (ADR-003)

Direct `SecurityReviewer` to detail the orchestration requirements for an isolated execution runtime using **gVisor** or **Firecracker MicroVMs**. Network constraints (`--net=none`) and ephemeral mount hooks must be documented inside `docs/adrs/ADR-003_SECURE_VALIDATION.md`.

### 📄 File Template Stub Generation Rule: `src/aegis/backends/base.py`

Direct `BackendEngineer` to output the exact abstract base classes using Python's native `abc` module:

```python
from abc import ABC, abstractmethod
from typing import Dict, Any, List, Generator

class AIAPIBackend(ABC):
    @abstractmethod
    async def generate_response(self, system_prompt: str, context: Dict[str, Any]) -> str:
        """Sends agent specific context prompts to the active LLM cluster."""
        pass

    @abstractmethod
    async def stream_response(self, system_prompt: str, context: Dict[str, Any]) -> Generator[str, None, None]:
        """Provides token-by-token server-sent streams for live tracking displays."""
        pass

class DebugBackend(ABC):
    @abstractmethod
    def extract_stack_trace(self, dump_file_path: str) -> Dict[str, Any]:
        """Invokes cross-platform debug binaries to parse call frames."""
        pass

class StorageBackend(ABC):
    @abstractmethod
    def save_state(self, incident_id: str, state_payload: Dict[str, Any]) -> bool:
        """Persists tracking graphs and consensus details to core datastores."""
        pass

class LogBackend(ABC):
    @abstractmethod
    def query_incident_window(self, target_service: str, start_time: str, end_time: str) -> List[str]:
        """Fetches lines from centralized sources (Fluentd, ELK, Datadog APIs)."""
        pass

class CodeBackend(ABC):
    @abstractmethod
    def get_commit_history(self, repo_path: str, lines_to_fetch: int, before_timestamp: str) -> List[Dict[str, Any]]:
        """Queries Git/Mercurial records to find system configuration changes before crash."""
        pass

    @abstractmethod
    def fetch_file_diff(self, repo_path: str, file_path: str, commit_sha: str) -> str:
        """Returns specific codebase mutations to assist the Code Analyst Agent."""
        pass

```
